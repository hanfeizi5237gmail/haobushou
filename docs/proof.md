- 素材：[`assets/screenshots/export.png`](../assets/screenshots/export.png)

### 会员授权

- 素材：[`assets/screenshots/membership.png`](../assets/screenshots/membership.png)
- 观察：会员中心显示套餐、授权编号、到期时间和设备激活数量。
- 运行范围：截图来自隔离本地测试授权，用于展示真实交互，不是客户账号或生产授权凭据。
- 产品事实：会员服务采用邮箱验证码登录；人工确认订单后签发固定天数授权，桌面端 Main Process 会再次校验权益。
- 生产边界：宣传页不把本地/隔离验证外推成生产邮件、支付或授权服务已全面开放；当前入口仍以人工开通说明为主。
- 当前价格：9.9 元 / 30 天、99 元 / 360 天；套餐天数由后台配置。

## 平台状态

- macOS Apple Silicon：已有本地候选制品，可进行有限试用。
- Windows：已生成交叉构建候选，但真实 Windows 安装、签名、SmartScreen 和独立人工验收仍未关闭，因此 README 使用“验证中”而不是“正式支持”。

## 合规和隐私边界

宣传内容只描述公开文章整理、本地归档和用户主动触发的同步能力。没有把以下内容写成现有能力：绕过验证码、防封、任意公众号全量抓取、无人值守无限同步、文章正文云共享、远程控制或自动支付。

反馈与诊断附件必须在上传前完成脱敏，去除 Token、Cookie、手机号、本地绝对路径和文章正文等敏感信息。

## 变更规则

新增宣传数字、截图或能力表述前，必须先补充同层级证据；没有真实安装/运行证据的内容只能放到“规划中”或“验证中”。
