# 号捕手

### 把微信公众号公开文章，变成可同步、可检索、可离线阅读、可批量导出的本地资料库

输入一篇文章链接，或从已验证的来源开始同步；内容落在你的电脑上，随时阅读、整理和导出。

> 号捕手是本地优先的公众号文章整理工具。它帮助研究、运营和内容团队把公开文章沉淀为自己的资料库；不承诺绕过验证码、平台限制或任意公众号的无限抓取。

## 先看它到底能做什么

**链接 → 同步 → 本地归档 → 阅读 / 导出**

1. 粘贴公开的 `mp.weixin.qq.com` 文章链接，或选择已经完成验证的来源。
2. 号捕手解析文章并以可恢复任务执行，失败、暂停和重试都有明确记录。
3. 正文、图片、任务和备份保存在本机 SQLite / 本地文件中，不上传你的文章库。
4. 在文章档案中检索、离线阅读，按需导出为 HTML、Markdown、Word、PDF、Excel 或 JSON。

## 为什么适合长期积累

- **本地资料库**：文章和任务是本地真相，网络波动后仍能继续整理和阅读。
- **可追溯同步**：任务中心显示发现、待抓、成功、失败和暂停，不用猜“到底抓了多少”。
- **多格式出口**：从单篇导出到批量导出，适配写作、备份、研究和团队交接。
- **失败可恢复**：支持暂停、恢复、取消、重试和重启恢复；已成功文章不会重复写入。
- **隐私边界清晰**：不把 Token、Cookie、手机号、本地绝对路径或文章正文写进日志和反馈附件。
- **会员能力可控**：账号、套餐、授权、设备和到期日由会员服务统一管理，客户端会再次校验权益。

## 三分钟上手

1. 安装号捕手并打开“链接收录”。
2. 粘贴一条你有权访问的公开公众号文章链接，点击“开始抓取”。
3. 在“文章档案”中阅读、筛选并导出；需要历史范围同步或批量能力时，再开通会员。

如果来源要求登录、人工验证或出现频控，请按界面提示完成验证或稍后重试，不要连续重复请求。

## 已知限制与合规边界

- 只处理公开页面或你已获授权访问的内容；请自行确认版权、转载和个人信息处理边界。
- 不提供任意公众号全量抓取、无限抓取、防封、绕过验证码、绕过平台限制或 100% 成功率承诺。
- 非官方来源可能出现漏收、延迟、验证码或页面结构变化；WeRead 仅定位为低频 B 级试点，不是官方长期接口。
- 文章、任务、SQLite、备份和导出数据默认留在桌面端；首期不做文章正文云上传、在线阅读、云端检索或远程控制采集。
- 诊断附件必须先脱敏：去除 Token、Cookie、手机号、本地路径、文章正文等敏感信息后再上传。
