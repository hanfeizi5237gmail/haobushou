## 30 秒理解号捕手

号捕手是一款本地优先的微信公众号文章整理工具。它把你想保存的公开内容，从“聊天里的一条链接”变成可检索、可阅读、可导出的本地文章档案。

你可以用它：

- **做研究**：把选题、行业资料和竞品文章沉淀下来，离线回看。
- **做运营**：按公众号和任务整理素材，明确哪些已抓取、哪些待处理。
- **做写作**：将文章批量导出为 Markdown、Word、PDF、HTML、EPUB、Excel 或 JSON，继续加工。
- **做长期备份**：文章、图片、任务和数据库默认留在自己的电脑里，不把文章库上传到号捕手服务器。

你不需要拥有目标公众号；但如果所选来源要求登录、人工验证或受到频控，需要按界面提示在本机完成验证，并接受该来源的覆盖范围和稳定性限制。

## 从链接到本地档案

| 01 输入 | 02 同步 | 03 沉淀 | 04 带走 |
| --- | --- | --- | --- |
| 粘贴公开文章链接，或选择已验证来源 | 任务可暂停、恢复、取消、重试和重启恢复 | 正文、图片、来源、处理链落到本地档案 | 单篇或批量导出，按需阅读和交付 |

### 01 · 输入公开文章或已验证来源

先从一篇公开文章开始，或使用已经完成登录/验证的来源。号捕手会在边界内识别链接，不把失败页面伪装成成功文章。

### 02 · 同步任务有进度、有失败出口

任务中心保留发现、待抓、成功、失败和暂停等执行事实。网络波动或人工暂停后，可以从持久化进度继续，不需要从头猜测。

### 03 · 本地文章档案可追溯

文章标题、公众号、来源、处理版本和资源状态一起保存；已归档内容可以脱离网络阅读。

![本地文章档案与处理链](./assets/screenshots/article-archive.png)

### 04 · 多格式导出，适配下一步工作

支持 HTML、Markdown、Word（DOCX）、PDF、EPUB、Excel 和 JSON 等出口。批量条数和完整数据库备份能力由当前套餐权益控制。

## 常见问题

**需要我拥有自己的公众号吗？**

不需要拥有目标公众号。公开文章链接可以直接开始；部分来源会要求你在本机完成一次登录或人工验证，实际可见范围以来源返回为准。

**能不能把任意公众号的全部历史文章一次抓完？**

不能这样承诺。号捕手处理公开内容或已授权来源，可能受群发范围、页面变化、验证码、频控和网络状态影响；遇到问题会显示失败或暂停，不伪造成功。

**文章会上传到云端吗？**

首期不上传文章正文、SQLite、备份或导出数据。它们默认留在桌面端；会员后台只处理账号、订单、授权、设备和反馈等商业化事实。

**会员和免费版差在哪里？**

免费版保留本地阅读和单篇基础导出；会员版按套餐权益开放批量导出、完整数据库备份和设备激活。API 与桌面端 Main Process 都会校验，不能靠隐藏按钮绕过。

**是否自动续费或自动扣款？**

没有。首期通过闲鱼或人工方式收款，确认后交付固定天数授权；到期后是否续期由用户再次购买决定。

**Windows 现在能不能正式下载？**

当前页面只把 Windows 标为候选验证中。真实安装、运行、签名和 SmartScreen 验收完成后，才会开放正式下载链接。

**如何反馈问题或建议？**

提交 [Bug 反馈](../../issues/new?template=bug-report.yml) 或[功能建议](../../issues/new?template=feature-request.yml)。截图和诊断日志上传前，请去除 Token、Cookie、手机号、本地路径和文章正文。

## 已知限制与合规边界

- 只处理公开页面或你已获授权访问的内容；请自行确认版权、转载和个人信息处理边界。
- 不提供任意公众号全量抓取、无限抓取、防封、绕过验证码、绕过平台限制或 100% 成功率承诺。
- 非官方来源可能出现漏收、延迟、验证码或页面结构变化；WeRead 仅定位为低频 B 级试点，不是官方长期接口。
- 不做文章正文云上传、在线阅读、云端文章检索、远程控制采集或自动续费。
- 诊断附件必须先脱敏：去除 Token、Cookie、手机号、本地路径、文章正文等敏感信息后再上传。

## 我们坚持的产品原则

竞品通常用“完整搬回”“不限额度”等一句话让人快速心动。号捕手选择把真实边界也写清楚：截图标注是真实运行还是界面示例，数字标注是单次快照还是普遍能力，尚未完成的平台和云能力放进路线图。这样你购买的是一个可验证、可恢复、数据留在本机的工具，而不是一句无法核对的承诺。
