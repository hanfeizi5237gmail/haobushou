## 图片口径

收录与文章档案来自真实运行；档案截图显示「等待离线归档」，不能说明该文章的全部资源已离线保存。阅读器与导出图为隔离界面示例，不代表真实文章库存或逐项导出验收。会员图来自隔离测试，不代表线上开通已经完成。

任务卡中的 98、94、54、1、39 是 2026-09-02 同一 WeRead 低频试点的不同阶段计数。54 指产生归档工件，不是所有图文完整离线的证明，整组数据不代表普遍容量、速度或成功率。

## 发布前核对

1. 确认对应安装包、套餐金额、授权期限和人工交付安排；Windows 实机与发布验证尚未完成，macOS Apple Silicon 签名与公证状态需确认。
2. 保留图文里的截图性质和能力边界，不补写任意公众号、全部历史、无限额度、防封或效率倍数，不虚构用户评价。
3. 只说明人工收款与固定期限授权，不写自动支付、自动续费或未经确认的退款政策。素材中的服务网址不代表线上购买链路已验收。
4. 软件授权与文章数据出售分开；使用公开或已授权内容也需遵守版权和来源平台规则。附件先脱敏，不在公开评论中处理凭证。
5. 发布当日核对各平台的软件授权、类目、外链和音乐规则，在发布预览中检查裁切及字幕遮挡。成片与配乐需另行审核。

以上是素材使用检查，不代表已通过平台合规审核。本轮只更新仓库，未向闲鱼、小红书或抖音发布。

## 重新生成

macOS 本机执行：

```bash
node marketing/render-social-assets.mjs
bash marketing/render-social-video.sh
```

图片渲染使用本机 sips，视频脚本使用已安装的 Python、OpenCV 和 NumPy，不需要外部生成式图片或视频服务。视频由静态卡片与淡入淡出组成；3:4 卡片等比置于 9:16 背景中，不拉伸 UI。音乐和配音不包含在生成产物中。
